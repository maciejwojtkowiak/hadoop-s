🐍 Hadoop Streaming (np. Python, Bash, Node.js)

Pipes / STDIN

Hadoop uruchamia Twój program jako osobny proces systemowy (fork/exec). Komunikacja odbywa się przez standardowe strumienie Unix (standard input/output).

// Jak Hadoop przekazuje dane do Mappera:
stdin  ⟶  [Wiersz tekstu CSV]  ⟶  sys.stdin
stdout ⟵  [klucz wartość ]  ⟵  print()
✓ Uniwersalność językowa: Dowolny język (Python, Ruby, Perl, Bash, C++).
✓ Brak kompilacji: Zmieniasz plik `.py` i od razu uruchamiasz zadanie.
⚠ Overhead IPC: Koszt serializacji tekstu i przełączania kontekstu procesów Unix.

☕ Hadoop Classic (Natywne Java API)

Natywne JVM

Zadanie wykonuje się bezpośrednio wewnątrz wirtualnej maszyny Java (JVM) TaskTrackera / Yarn NodeManagera. Klasy dziedziczą po Mapper i Reducer.

// Przekazywanie obiektów w pamięci JVM:
Context.write(K2 key, V2 value)  ⟶  obiekty Writable
Brak rzutowania stringów – silne, statyczne typowanie
✓ Maksymalna wydajność: Zero narzutu na procesy zewnętrzne i konwersję IPC.
✓ Zaawansowana kontrola: Własne partycjonery, WritableComparable, binarna serializacja.
⚠ Złożoność budowy: Wymaga Mavena, kompilacji do `.jar` i obsługi wyjątków Java.

🔄 Szczegółowy Cykl Życia Rekordu w Hadoop MapReduce

1 Input Split & Read

HDFS dzieli plik `reservations.csv` na bloki. LineRecordReader czyta wiersze i przekazuje je do Mappera.

2 Map & Local Combine

Mapper parsuje rok i status. Combiner łączy cząstkowe sumy na węźle, zmniejszając ruch sieciowy (Shuffle).

3 Shuffle & Sort

Hadoop automatycznie sortuje rekordy według klucza (hotel_id, year) i kieruje wszystkie te same klucze do jednego Reducera.

4 Reduce & Final Output

Reducer sumuje ostateczną liczbę i wylicza avg_price = sum_price / count. Wynik ląduje w HDFS dla Hive.

Przykład transformacji pojedynczego rekordu:
Wejście CSV: ...,HOTEL0001,GUEST1,2024-03-20T15:00,...,780.00,Cancelled
Mapper emituje ⟶ HOTEL0001 2024 780.00,1
Combiner emituje ⟶ HOTEL0001 2024 1,780.00,1 (liczność, suma, anulacje)
Reducer emituje ⟶ HOTEL0001 2024 102 981.17 34

          ⚠️ Laboratorium Błędów: Co Najczęściej Psuje Ocenę?
        

        

          Kliknij dowolny błąd, aby zobaczyć dlaczego odejmuje punkty i jak wygląda prawidłowy kod.
        


        

          
          
          

            

              ❌ Błąd 1: Brak pominięcia nagłówka CSV (M01)
            

            
Wiersz nagłówkowy wpada do obliczeń i wywala ValueError: could not convert string to float: 'price'.

          


          
          

            

              ❌ Błąd 2: Buforowanie w pamięci (M05)
            

            
Użycie records.append(line) w mapperze łamie przetwarzanie strumieniowe i zabija pamięć klastra.

          


          
          

            

              ❌ Błąd 3: Liczenie średniej w Mapperze (M03)
            

            
Średnia nie jest dystrybutywna. Mapper musi emitować sumę i liczność, a nie gotową średnią.

          


          
          

            

              ❌ Błąd 4: Użycie LOAD DATA w Hive (H02)
            

            
LOAD DATA INPATH fizycznie przenosi pliki w HDFS i niszczy dane wejściowe. Wymagane jest EXTERNAL TABLE ... LOCATION.

          


          
          

            

              ❌ Błąd 5: Sklejanie JSON przez CONCAT (H15)
            

            
Ręczne tworzenie JSON stringa. Wymagane jest oficjalne org.apache.hive.hcatalog.data.JsonSerDe.

          


          
          

            

              ❌ Błąd 6: Użycie ROW_NUMBER() zamiast RANK() (H09)
            

            
W przypadku remisów obłożenia hotele muszą otrzymać tę samą pozycję (1, 2, 2, 4), a nie kolejne numery.

              1. Test lokalny potoku w 1 linijce (bez Hadoop):
              
            

            
cat data/datasource1/*.csv | python3 mapreduce/mapper.py | sort | python3 mapreduce/combiner.py | sort | python3 mapreduce/reducer.py | head -15

          


          
          

            

              2. Uruchomienie Hadoop Streaming z Combinerem:
              
            

            
mapred streaming -files /opt/mapreduce/mapper.py,/opt/mapreduce/combiner.py,/opt/mapreduce/reducer.py -input /user/root/input/reservations -output /user/root/output/mr_results -mapper "python3 mapper.py" -combiner "python3 combiner.py" -reducer "python3 reducer.py"

          


          
          

            

              3. Uruchomienie Apache Hive przez Beeline:
              
            

            
beeline -u "jdbc:hive2://localhost:10000/default" -n root --hivevar input_dir3="/user/root/output/mr_results" --hivevar input_dir4="/user/root/input/hotels" --hivevar output_dir6="/user/root/output/hive_results" -f /opt/hive_scripts/hotel_ranking.hql

          


          
          

            

              4. Weryfikacja formatu JSON SerDe w HDFS:
              
            

            
hdfs dfs -cat /user/root/output/hive_results/* | head -20
